# 🎨 Personal Portfolio Website

A modern, animated portfolio website built with cutting-edge web technologies. This site showcases my projects, certifications, hackathon experiences, and volunteer work with smooth animations and a clean design.

---

## 🛠️ Tech Stack Explained (The Human Way)

### **Next.js 14** - The Framework
Think of Next.js as React on steroids. Instead of just building interactive UI components, Next.js lets you build entire web applications that are super fast and easy to deploy. It handles all the boring stuff like routing (moving between pages), building your site for production, and optimization automatically.

### **React 18** - The UI Library  
React is like LEGO blocks for web interfaces. Instead of writing plain HTML and JavaScript, you create reusable components. Need a button that does something? Create it once, use it everywhere. React figures out what changed on the page and updates only that part—making everything super fast.

### **TypeScript** - The Safety Net
JavaScript is flexible, but sometimes *too* flexible. TypeScript adds type checking—it's like having a spellchecker for your code. It catches bugs before they happen by making sure you're using variables correctly. "Oops, you passed text when the code expects a number?" TypeScript tells you right away.

### **Tailwind CSS** - The Styling Tool
Forget writing tons of CSS files. Tailwind gives you pre-made utility classes like `bg-blue-500` and `rounded-lg` that you can combine in your HTML. It's like having a design system that's already built—you just mix and match to create beautiful layouts without writing custom CSS.

### **Framer Motion** - The Animation Magic
Want smooth, professional animations that make your site feel alive? Framer Motion handles that. Hover effects, page transitions, scrolling animations—all with simple, readable code. It's what makes the portfolio feel premium and polished.

### **ESLint** - The Code Reviewer
ESLint is your automated code reviewer. It checks your code for common mistakes, inconsistent formatting, and bad practices. Think of it as a coworker who reviews every line before you commit to make sure everything follows best practices.

## 🚀 Quick Start

**1. Install dependencies:**
```bash
npm install
```

**2. Run the dev server:**
```bash
npm run dev
```

**3. Open your browser:**
Navigate to `http://localhost:3000` and you're done! The site auto-refreshes as you make changes.

## 📁 Project Structure

```
├── app/              # Main app pages and layouts
├── components/       # Reusable React components (Hero, Skills, Projects, etc.)
├── lib/              # Data and utilities (portfolio data lives here)
├── public/           # Images, certificates, and static assets
└── package.json      # Project dependencies
```

---

## 🏗️ Building & Deployment

**Build for production:**
```bash
npm run build
npm start
```

This creates an optimized version of your site that's ready to deploy. It's smaller, faster, and perfect for putting live on the internet.
